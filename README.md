# SkyCast — Modern Weather App

A polished, responsive weather website built with vanilla HTML, CSS, and JavaScript.

## Features

- Live current weather
- City search with suggestions
- Browser geolocation
- Celsius / Fahrenheit switch
- 24-hour forecast
- 7-day forecast
- Sunrise and sunset
- Humidity, wind, pressure, cloud cover, rain and wind direction
- Recent searches stored locally in the browser
- Responsive glass-style interface
- No API key required

## Weather API

This project uses the free [Open-Meteo](https://open-meteo.com/) forecast and geocoding APIs.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages

A GitHub Actions workflow is included in `.github/workflows/pages.yml` to publish the site automatically from the repository root.
